# 2.6.0 migration guidance

These changes shipped in 2.6.0. This page preserves the guidance previously held in the unreleased notes; the
[GitHub Release](https://github.com/albumentations-team/AlbumentationsX/releases/tag/2.6.0) contains the full release notes.

- Fixed delayed release of input arrays and CPU tensors after `Compose` calls, including calls that raise an exception.
  Optional-channel images, masks, batches, and volumes no longer depend on cyclic garbage collection for release.
  Existing callers need no migration. This addresses [#596](https://github.com/albumentations-team/AlbumentationsX/issues/596).
- `SamplingContext.invocation` and the `invocation=` constructor argument were removed. Use `sampling.py_random`,
  `sampling.random_generator`, the sampling hook's `data` and `targets`, or `SamplingContext.from_seed()` / `from_owner()`.
  See the [custom sampler migration guide](../contributing/coding_guidelines.md#samplingcontext-compatibility-and-migration).
